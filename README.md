# Quick-Note-Application
A Quick Note Application built using Flask and SQLite that allows users to create, edit, delete, and store notes dynamically.

A simple Quick Note Application built using HTML, CSS, JavaScript, Python Flask, and SQLite. This application allows users to create, edit, and delete notes dynamically with permanent database storage.

Features:

Add Notes
Edit Notes
Delete Notes
SQLite Database Storage
Responsive User Interface

Technologies Used:

HTML
CSS
JavaScript
Python
Flask
SQLite
